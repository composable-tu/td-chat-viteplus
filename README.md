# Vue + VitePlus 项目

## 第一次使用

请先在本地计算机安装 Vite Plus。Vite Plus 是由 VoidZero 公司开发的 Vite 的生态增强版：

### macOS / Linux

```bash
curl -fsSL https://vite.plus | bash
```

### Windows

```powershell
irm https://vite.plus/ps1 | iex
```

然后在该项目根目录运行以下命令以安装依赖：

```bash
vp install
```

## 运行项目

```bash
vp dev
```

## 构建项目

```bash
vp build
```
